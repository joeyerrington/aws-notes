# AWS Solutions Architect Associate revision notes

A public, unofficial AWS SAA-C03 revision guide. Built from personal study notes, reorganised into 14 capability categories.

## What's included

- 126 service and reference entries
- Each entry has **What**, **Use / avoid** and **Exam** summaries
- Original detailed study notes, expandable per entry
- Cross-service comparisons
- Search across summaries and original notes
- Mobile-responsive, VS Code-inspired dark interface
- No dependencies, build step, tracking or backend

## Run locally

Open `index.html` in a browser. No `npm install` or server required.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html` and this README to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the published URL once deployment completes.

## Content and accuracy

This is an independent community study guide, not official AWS guidance. The source notes were written for personal revision and preserved for reference. They can include outdated limits, terminology or inaccuracies. The short editorial summaries were added for this public edition. Verify facts and pricing against current AWS documentation before relying on them.

Some historical or retired AWS services are explicitly marked as such. Exam coverage can change.

## Editing

`index.html` is self-contained. Service data is embedded in the `DATA` variable in the inline script. You can edit it directly, or regenerate from the source JSON using the included `aws_notes_data.json` as your content source.
